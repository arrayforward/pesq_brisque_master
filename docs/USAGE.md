# 使用手册

## 安装与首次启动

1. 安装 `app-debug.apk`（EMUI 会弹"未知来源安装确认"，点"继续安装"）
2. 首次打开自动弹出权限说明 → 点"确定" → 系统授权框点"允许"（RECORD_AUDIO）
   - 拒绝后会提供"去设置/重试"
3. 建议先在目标 App（音乐/视频）中准备好要播放的内容

## Tab 1：画面 + 音频评估

1. （可选）在「配置」Tab 设置等待时长（默认 5 秒）和画面录制时长（默认 10 秒）
2. 点「开始评估（画面+音频）」→ 系统弹"屏幕录制"授权 → 点"立即开始"
3. 倒计时开始（大号数字 + 通知栏同步），立即切回目标 App 开始播放
4. 录制中大数字变为剩余秒数，进度条推进
5. 结束后自动逐帧打分（状态栏显示"打分中 n/总数"），完成后展示：
   - 最高 / 最低 / 平均 / 去极值平均（去最高 5、最低 3）
   - 逐帧列表：帧号 + 分数条 + 分数 + 质量标签
   - 音频区：MOSNet MOS + P.563 MOS-LQO + 频谱指标
6. 点击任意帧行 → 全屏查看该帧 → 「另存为」存到相册 `Pictures/PesqMeter/`

## Tab 2：音频长录音评估

1. 「配置」Tab 设置音频录制时长（5~600 秒，默认 30）
2. 点「开始音质评估 (MOSNet + P.563)」→ 授权 → 倒计时期间切到目标 App 播放
3. 每 10 秒出一个分段分（状态栏与日志实时滚动），结束自动给平均分

## Tab 3：日志

- 全部状态/进度/分段分带时间戳记录
- 截屏或录音启动失败时，完整异常堆栈打印在此（同时写入 logcat，tag=`PesqMeter`）

## Tab 4：配置

| 配置项 | 默认 | 范围 |
|---|---|---|
| 等待时长 | 5 秒 | 0~30 |
| 画面录制时长 | 10 秒 | 5~60 |
| 音频录制时长 | 30 秒 | 5~600 |

## 选对测试内容（重要）

- **音频**：用真人语音（新闻、有声书）评估才能得到合理高分（清晰语音 MOSNet 3~4.5 / P.563 3.5~4.3）；音乐会系统性偏低
- **画面**：用自然场景实拍视频才能得到正常区间（20~50）；UI/文字/动漫会打到 80~110
- 分数用于"同内容、不同 App"横向对比，不要当绝对值

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 音频无分数，日志"最大振幅 0" | 目标 App 禁止回放采集，换 App |
| 画面 80~110 分 | 屏幕内容对 BRISQUE 属域外，正常，看相对差异 |
| MOS 很低但声音正常 | 播放的是音乐，换语音内容验证 |
| 安装卡住 | 手机上点"继续安装" |
| 帧图片没了 | 每次开始新评估会清空旧帧 |
